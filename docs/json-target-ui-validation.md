## 実装

|項目|現在の動作|
|---|---|
|ツリー|ルートだけ初期展開。開閉とラジオ選択を分離。空コンテナに開閉ボタンなし。ルートは全型、入れ子は object/array のみ選択可能|
|ページと仮想窓|同じ親の子50件ごとにページ表示。展開後の全行数を数え、要求窓の最大300行だけ返す。48px固定行と上下スペーサー。字下げ最大64px、深さ128の Pointer は保持|
|位置復元|祖先の展開・親のページ・仮想窓を復元し、DOM反映後に対象ラジオへフォーカス。閲覧・Tab・スクロールでは対象を変更しない|
|対象詳細|完全な絶対 JSON Pointer と対象名を JSON 文字列で表示。型・直下件数・部分木の説明、直下10件ごとのページ|
|JSON詳細|開いたときだけ元トークン範囲を逐次整形し、10,000コードポイントで停止。全文 stringify 後の切捨てはしない。元数値字句・文字列エスケープを保持。抜粋と変換出力を区別する案内|
|方式の適合性|3方式それぞれの説明・行/列/ノード数・不適合理由。不適合な未選択方式は無効。選択済み方式は不適合でも保持し、現在の判定完了後だけ確定を許可|
|取消と状態|表示状態だけ File identity ごとに WeakMap でメモリ保持。draft は再表示時に確定値から初期化。取消・Escape・背景クリックで draft を破棄し確定済み結果を保持|
|非同期境界|要求 ID・operation・Worker 世代を照合。閲覧取消は該当 pending を破棄し遅延応答を不採用。閲覧取消だけでは Worker を終了せず解析セットを保持。全体取消/破棄は従来どおり Worker 終了|

解析・生成ライブラリは Worker 側を維持。初期値のために core を main bundle に読み込まない。新規依存、CSP変更、SW変更はない。

## 失敗分析

- 環境問題: サンドボックス内の別実行で Vitest 一時ファイルの rename が EPERM。テスト本体へ到達していない。通常環境での成功と分けて記録した。
- テスト前提の問題: TU-10 初版は親を順に展開し、仮想窓の外へ出た次の親を直接クリックしようとした。trace の locator 待ちで検出。親を逆順に展開し、窓移動を明示的なスクロールで確認する手順へ修正した。
- テスト実装問題: 完全な対象名を追加した際に Pointer と同じ CSS クラスを使い locator が二要素に一致。クラスを分離し再検証した。タイムアウト延長による対処はしていない。
