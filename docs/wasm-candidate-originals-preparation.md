# anydoc 候補原文の限定的なオフライン準備

2026-11-05、PR #35 マージ後の main `e0aee9ceb1ec75ddeb4339556c65d9a8beeca916` を基点とする。`encoding_rs 0.8.35` と `unicode-ident 1.0.24` は[既存の調査](distribution-source-triage.md)で AND を含むライセンス式と原文が確認された候補。保守的な準備として両候補の原文を追加するが、公開 WASM にリンクされた証明、他の依存や配布条件の充足ではない。実機はユーザー別途、macOS/iOS は対象外。アーカイブの公開・添付とデプロイは行わない。

## 先に定める検証観点

最優先は、別版・改変された原文を表示すること、候補を実リンク確定や条件充足と誤認させること、オフラインで必要な本文へ到達できないこと。機能は一覧・原文への到達、非機能はオフラインと資産容量、データは版・原文 bytes/hash・AND/OR の保持、UI は候補である旨の表示を確認する。正常は全7原文の一致と閲覧、異常は欠落・改変・版不一致、境界は一つの依存に複数原文、状態遷移はオンライン準備→オフラインを分ける。実機・実配信は今回のローカル E2E と分離する。

## 対象・判断の範囲
