# 配布準備の完了・残作業・判断待ち

2026-11-11。ユーザー承認の方針変更により、確認済みの工程を閉じ、外部確認と公開受入を内部の調査残件へ混ぜない。PR #46のレビュー用ブランチを対象とし、mainへのマージ・公開承認ではない。以下を現行の作業管理の正とし、旧判断表と過去報告の「未確認」をそのまま再起票しない。

## 評価前の観点

|観点|正常|異常|境界|状態遷移|
|---|---|---|---|---|
|機能|既存証拠で工程を閉じる|原文欠落/改変を完了としない|調査完了と条件履行・公開承認を分ける|調査→内部作業/外部判断/受入|
|非機能|固定版・hash・履歴を再利用|取得失敗や証拠不足を対象外にしない|完全SBOMや全再ビルドを一律要求しない|新しい有効な証拠でのみ再開|
|データ|全候補を一括分類し過去記録を保持|新旧版・候補/実対象を混同しない|未観測を非内包としない|閉じた工程を根拠なく戻さない|
|UI/報告|残作業の担当と完了条件を明示|資料収集を配布承認と表示しない|外部/ユーザー待ちを作業進捗へ混ぜない|作業数ではなく閉じた項目で報告|

まず防ぐのは「無根拠の完了」と「同じ調査の無期限な継続」の両方。既存の固定候補の原文・告知案をまとめて補うため、資料hash/対象件数/状態の整合、文書/配布物検査、PWA対象1件を逐次実施する。正常な全候補提供、欠落/改変/WASM版違いの拒否、候補と公開承認を混同しない表示を検査する。全件/他ブラウザー/実機/実配信はローカルでは未実施。
