- まず防ぐべき不具合との関係/影響度（致命・重大・軽微）:
- 観測事実と原因仮説を分離:
- 分類（テスト観点不足/データ問題/環境問題/実装問題/原因未確定）:
- 単独/通し、初回/再実行での差、前提条件の崩れ:
- 回復方法/回復できたか/再発防止に必要な検査:
- 終了時の専用ウィンドウ/preview停止、倍率/負荷の復旧:
